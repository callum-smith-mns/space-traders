# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Please do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email the maintainer directly or use [GitHub's private vulnerability reporting](https://github.com/callum-smith-mns/space-traders/security/advisories/new).

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | Yes       |

## Security Practices

- Dependabot alerts and security updates are enabled
- Secret scanning and push protection are enabled
- Branch protection requires pull request reviews before merging
- Force pushes and branch deletion are blocked on `main`
